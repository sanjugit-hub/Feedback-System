# Feedback System

A web-based feedback management module developed for the Database

This module enables website visitors to submit feedback, suggestions, and comments through an online form. Submissions are stored in a MySQL database, compiled into PDF reports, and delivered through automated email notifications.

### Key Features
- User-friendly feedback submission form
- MySQL-based feedback storage and management
- PDF generation for individual submissions
- Automated email notifications via Gmail SMTP
- Email forwarding support
- Optional visitor details collection

### Technologies Used
Python | HTML | CSS | MySQL | Apache HTTP Server | Gmail SMTP

### Project
Part of the MIsoTEx Database Development initiative at IBAB, Bangalore.
